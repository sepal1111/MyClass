# MyClass 課堂即時記錄系統

給國小教師使用的課堂管理工具：點名、加減分、分組、座位表、作業與測驗、即時互動牆，一套搭配大螢幕投影與學生手機／平板的區網系統。整個系統以單一 Node.js 伺服器執行，資料存在本機的 SQLite，不需要連到任何雲端服務，打包成免安裝的可攜版（可放隨身碟）。

## 功能

**教師端**
- 課程與學生名冊：導師／科任模式、文字貼上／CSV／Excel 匯入、學生照片
- 出缺席點名：出席、病假、事假、公假、喪假、遲到，保留點名歷程
- 量化加減分與排行榜：自訂評分規則、個人／多選／整組批次加分，當日、區間、學期累計
- 彈性分組：多套分組方案、自動分組；座位表與自動排座（隨機／性別平衡）
- 質性紀錄：文字備忘錄與圖片、影音附件；教學日誌、班級佈告欄
- 大螢幕投影：Socket.io 即時同步，手機／平板遙控加分，隨堂工具（倒數計時等）
- 課程素材：單元／小單元／教材（檔案、連結、YouTube），閱讀進度統計
- 作業與線上測驗：個人或小組繳交、評分、鎖定／退回；測驗自動批改、CSV 題庫匯入
- 即時互動：互動牆、文字雲、檔案收集、學生去向、點數卡與獎勵兌換
- 課表提醒、紙本測驗、題庫與報表（Excel 匯出）
- 作業掃描登記：僅限教師本機使用

**學生端**
- 以帳號與密碼登入，從手機或平板瀏覽教材、繳交作業、線上測驗、參與互動牆與兌換獎勵
- 選用：學生在家上線（透過 Tailscale Funnel，只開放學生功能，見下方「學生在家上線」）

## 技術

Node.js 22、Express、Socket.io、TypeScript、Prisma（SQLite）、純 HTML／JavaScript 前端（不依賴前端框架）。

## 快速開始（開發）

```bash
npm install
npm run dev
```

`npm run dev` 會自動尋找從 8000 起算的可用連接埠、建立或更新 SQLite 資料庫（`bin/classroom_record.db`）、產生自簽 TLS 憑證，並在伺服器就緒後開啟瀏覽器，同時在終端機印出供學生掃描的 QR Code。

需要正式編譯時：

```bash
npm run build   # prisma generate + tsc
npm start       # node dist/index.js
```

## 登入與安全設定

- 教師登入密碼為「**字頭 + 當天月日**」，例如字頭是 `MyPrefix`、今天是 10 月 14 日，密碼就是 `MyPrefix1014`。
- 全新安裝的預設字頭為 `Admin`，**第一次登入後系統會強制要求修改字頭**，改完才能使用其他功能。新字頭至少 4 碼且不可為 `Admin`。
- 「忘記密碼」的重置**只能在執行程式的那台電腦**操作，不需要舊字頭；區網其他裝置、以及經由 ngrok／cloudflared 等反向代理或通道轉進來的請求（帶有 `X-Forwarded-For` 等標頭）都會被拒絕。
- 非教師本機的登入嘗試，10 分鐘內失敗 8 次會暫停該來源 10 分鐘（教師本機不受限制）。
- 學生以個別帳號登入（帳號不分大小寫），預設密碼為**學號**（沒有填學號的學生退回座號四碼，例如 5 號為 `0005`）。**學生第一次登入時必須先自己設定新密碼**（在校內沒有任何規則限制，只要不是空白；要在家登入則須符合外網密碼門檻，見「學生在家上線」）；在設好之前，除了「我的資料」與改密碼之外的學生 API 都會回 403。之後可在右上角「🔑 密碼」再修改；教師在學生資料中重設密碼後，學生下次登入會再次被要求設定。
- **密碼提醒**：學生可寫下「前綴＋主要內容說明＋後綴」（主要內容必填、前後綴至少一個，例如 `xy` ＋「媽媽的電話號碼」＋ `sd` ＝「xy媽媽的電話號碼sd」）；在登入畫面輸入帳號後密碼連續輸錯 3 次，就會顯示該帳號的提醒。前綴與後綴是密碼的真實內容，任何人知道帳號並輸錯都看得到，請提醒學生不要寫入完整密碼。
- 教師可在學生名冊對單一學生「恢復預設密碼」（回到學號、學生下次登入須重設、清除提醒），名冊並標示學生是否已自訂密碼。
- 學生登入以「帳號」計算失敗次數：10 分鐘內失敗 10 次，暫停該帳號 5 分鐘（教師本機不受限制）。
- 預設監聽所有網卡，讓區網內的學生裝置能連入。若只在教師本機使用，可設定環境變數 `MYCLASS_HOST=127.0.0.1`，伺服器就只接受本機連線。
- 跨來源請求（CORS）僅允許同源；所有資料（資料庫、照片、上傳檔、憑證）都在程式旁的 `bin/`，不會上傳到外部。
- 首次啟動時會在 `bin/certs/` 為本機自動產生自簽憑證，每份安裝各自獨立，**不要把 `bin/` 提交到版本控制或隨程式散布**（已列於 `.gitignore`）。

## 學生在家上線（選用）

讓學生在家也能看教材、作業與成績並繳交作業。資料仍只存在老師電腦，透過 [Tailscale Funnel](https://tailscale.com/kb/1223/funnel) 由老師電腦主動往外連，不需要固定 IP、網域或設定防火牆。**預設關閉**，沒有啟用時系統行為與校內使用完全相同。

- **啟用**：在 `bin/` 新增 `remote_access.json`（內容 `{ "enabled": true, "port": 8100 }`）或設定環境變數 `MYCLASS_REMOTE_PORT=8100`，伺服器會另外在 `127.0.0.1:8100` 開一個「學生專用入口」，再用 `tailscale funnel --bg 8100` 對外開放。
- **給老師的圖文設定教學**：MyClass 執行時開啟 `/remote-guide`（檔案為 `static/remote-guide.html`），老師使用手冊目錄也有連結。
- **學生專用入口**（`src/remoteGateway.ts`）只綁本機、以白名單轉送：學生頁面、學生 API、附件與 Socket.io；教師頁面與 API 一律 404，教師每日密碼不會暴露在網際網路。轉送時移除 cookie 等教師憑證並標記為外網請求。
- **外網限制**（只影響在家連線）：

| 項目 | 規則 |
|---|---|
| 密碼門檻 | 至少 8 字且含英文與數字；仍使用預設密碼（學號）的帳號不能在家登入 |
| 登入失敗 | 依來源 IP（10 分鐘 30 次 → 封鎖 15 分鐘）與帳號（10 分鐘 10 次 → 只封鎖該帳號的外網登入 15 分鐘）分開計算，不影響校內登入 |
| 密碼提醒 | 外網一律不顯示 |
| 登入有效期 | 外網只接受簽發 7 天內的憑證；改密碼或教師重設密碼後所有舊憑證立即失效（校內亦同） |
| 上傳 | 每檔 50MB（作業、紙本小考照片、即時互動牆校內也是 50MB；檔案蒐集校內 250MB） |
| 附件 | 只能讀自己班級的教材、互動牆圖片與自己（或自己小組）的作業、檔案；觀察紀錄與日誌附件一律拒絕 |
| 錯誤訊息 | 外網只顯示一般性訊息 |

## 新版本偵測

打包版（可攜版）啟動後，會在背景向 GitHub 查詢最新發佈的版本；有新版時，老師登入後畫面上方會出現提示，並說明更新步驟。**只通知，不會自動下載或更換任何檔案。**

- **只傳送什麼**：對 `api.github.com` 的一個匿名 GET（沒有班級、學生、教師或機器識別資料）。每 12 小時最多一次，失敗時靜默略過。
- **怎麼關閉**：「設定 ➔ 密碼與連線 ➔ 軟體更新」取消勾選；或設定環境變數 `MYCLASS_NO_UPDATE_CHECK=1` 強制停用。
- **目前版本**來自打包時寫入的 `system/version.json`（由 git 標籤產生）；開發模式沒有版本，功能不啟動。
- **使用者怎麼取得更新**：更新視窗會直接提供可攜版 zip 的下載連結並說明步驟。可攜版的封裝結果是「`MyClass.exe`（托盤）＋伺服器執行檔＋`system/` 資料夾」，使用者的資料在旁邊的 `bin/`；更新就是換上新的資料夾，再把舊的 `bin/` 複製過去。
- **舊版安裝版的使用者**：v4.3.0 起不再提供安裝版。系統仍會辨識安裝版（程式資料夾有 `unins000.exe`），更新視窗改為說明「下載可攜版 → 結束 MyClass → 複製 `C:\MyClass\bin` → 解除安裝舊版 → 開啟新的 `MyClass.exe`」。v4.2.x 以前的安裝版看到的是舊程式內建的說明（找不到 Setup 時導向 Release 頁），所以 **Release 說明也要寫上這段換版步驟**。
- **發佈新版本**（維護者）：
  1. `build-win.bat` 打包；完成後 `release/` 只有 `MyClassV<版本>-win-portable.zip`（**不含 `bin/`**，內附 `HOW-TO-UPDATE.txt`）。
  2. `npm run package:release` ➔ 列出該版本要發佈的檔案、大小與雜湊，並印出建立 Release 的步驟與 `gh release create` 指令。
  3. 打上 `v<版本>` 標籤並推送，在 GitHub 建立同名 **Release**，附上 zip。
  - 附件檔名須維持上述命名（含 `portable.zip`），更新視窗才能挑出對應的檔案；挑不到時會改為導向 Release 頁面。
  - 偵測依據是 Release（沒有 Release 時退而求其次看標籤）；草稿與預先發行版不會通知使用者。
- 若儲存庫改名或搬家，用環境變數 `MYCLASS_UPDATE_REPO=帳號/儲存庫` 指定，或修改 `src/updateCheck.ts` 的預設值。

## 資料安全與外洩風險

班級、學生、成績、照片、上傳檔與備份都存放在程式旁的 `bin/`，**沒有加密**（資料庫是一般的 SQLite 檔案）。「忘記密碼」可以在執行程式的那台電腦直接重設，因此**只要程式連同 `bin/` 一起遺失、被複製或被借用，登入密碼擋不住資料被讀取**。程式內加密也無濟於事，因為程式本身會跟著一起被帶走。

- **只有程式外流（沒有 `bin/`）不會洩漏任何資料**；發佈用的壓縮檔（`npm run package:release`）一律排除 `bin/`。
- 分享程式給他人時只給執行檔與 `system/`；不要把含 `bin/` 的資料夾寄信、上傳雲端或交給他人；`bin/backups/` 的備份同樣含有全部資料。
- 隨身碟與筆電請妥善保管；需要更高保護請用 BitLocker 或加密隨身碟保護整顆磁碟。
- 不要用 ngrok、cloudflared 等工具把整個系統（8000 埠）直接開放到網際網路；要讓學生在家上線，請只使用內建的學生專用入口（見「學生在家上線」）。
- 隨身碟遺失或電腦被盜，請視同學生個資外洩，依學校規定通報。
- 系統在登入畫面、教師首頁與「設定 ➔ 密碼與連線」都會顯示這項提醒。

## 打包

| | Windows 可攜版 | macOS 可攜版 |
|---|---|---|
| 建置 | `build-win.bat`（`npm run build:exe:win`） | `build-mac.command` 或 `build-mac.sh`（`npm run build:mac`） |
| 輸出（只留壓縮檔） | `release\MyClassV版本-win-portable.zip` | `release/MyClassV版本-Mac*.zip` |
| 啟動 | 雙擊 `MyClass.exe`，背景執行並在通知區顯示圖示（伺服器執行檔在 `system\MyClassV版本.exe`，資料夾最上層只有 `MyClass.exe`） | 雙擊資料夾內的 `.command` |
| 資料位置 | 資料夾內 `bin\` | 資料夾內 `bin/` |

v4.3.0 起不再提供 Windows 安裝版（Inno Setup）：托盤程式與開機自動啟動都已併入可攜版，兩者功能相同。

- **封裝完成後 `release/` 只會留下壓縮檔**：可攜版資料夾裡的執行檔約 140 MB（超過 GitHub 單檔 100 MB 上限），壓縮後約 90 MB。zip 不含 `bin/`（使用者資料），並附 `HOW-TO-UPDATE.txt`（內容取自專案根目錄的 `初始密碼與更新文件.txt`，直接編輯該檔案即可，下次封裝就會帶入）。要保留解壓縮後的資料夾（例如本機直接測試），封裝時加 `--keep-folder`（`node scripts/build-exe.mjs win --keep-folder`）或設定環境變數 `MYCLASS_KEEP_FOLDER=1`。
- **Windows 防火牆**：伺服器第一次執行時，Windows 會詢問是否允許存取，按「允許」後區網內的學生裝置才連得進來。老師電腦沒有系統管理員權限時，請資訊組協助按允許，或手動新增允許 `system\MyClassV版本.exe` 的輸入規則。
- 通知區托盤程式 `MyClass.exe`（`tools/tray/MyClassTray.cs`）在 `build-exe.mjs win` 時以 Windows 內建的 `csc.exe` 編譯並放進可攜版，不需另外安裝 SDK（找不到 `csc.exe` 時只警告，封裝結果不含托盤）。它負責隱藏啟動伺服器、意外結束時自動重啟，並提供開啟系統、複製學生連線網址、開機自動啟動（寫在目前使用者的開機啟動登錄值，不需要系統管理員）等選項。因為可攜版更新是換新資料夾，老師手動開啟托盤時，若開機自動啟動指向別的資料夾，會自動改成指向自己。
- 升級時只換程式檔，`bin/` 由使用者複製到新資料夾。每次程式版本改變後的第一次啟動，會先把資料庫備份到 `bin/backups/`（保留最近 10 份）。
- 同一份資料已有伺服器在執行時，再次啟動只會開啟既有網址，不會同時開兩個程序寫同一個資料庫。

## 專案結構

```
src/
  index.ts            Express + Socket.io 進入點、頁面與靜態檔路由
  db.ts               Prisma 初始化與等冪的資料表／欄位遷移
  paths.ts            可攜路徑（bin/、uploads/、photo/）
  runtime.ts          單一執行個體、背景模式與安全關閉
  backup.ts           升級前自動備份資料庫
  tls.ts              自簽憑證產生
  realtime.ts         Socket.io 房間與即時廣播
  middleware/         教師 session、學生 JWT、僅限本機的閘門
  routes/             各功能模組的 REST API
  utils/              匯入解析、評分、上傳等共用工具

scripts/              Windows／macOS 打包與圖示產生腳本
tools/tray/           Windows 通知區托盤程式
tools_cards/          點數卡片批次產生工具（Python，獨立使用）
```

## 常見問題

**iPhone 連不上，但平板可以？**
iPhone 同時有 Wi-Fi 與行動數據時，iOS 可能把流量送往行動網路，導致到不了校內伺服器（常見於伺服器是公開 IP、學生裝置經 NAT 連入的校園網路）。請先**關閉行動數據**，只用 Wi-Fi；也可以在「設定 → 行動服務 → Wi-Fi 輔助」關閉。

**第一次連線出現「此連線不是私人連線」？**
伺服器使用自簽憑證。點「顯示詳細資訊 → 造訪此網站」即可。憑證重新產生（換 IP 或到期更新）後需再確認一次。
