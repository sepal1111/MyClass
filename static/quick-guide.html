MyClass 老師快速上手

不用懂電腦，3 分鐘就看懂

按「下一頁 ▶」、鍵盤 ← → 或左右滑動換頁

先認識 5 個大項

🚀課堂進行上課時用：評分、排行榜、抽籤、計時、互動遊戲
📋班級經營每天用：點名、誰不在教室、教學日誌
📚教材與作業放教材、收作業、收照片影片、紙本小考
🏆激勵與統計獎勵兌換、點數卡、匯出報表
⚙️設定學生名單、座位表、分組、課表、連線
🧰右下角小工具列隨時可按：計時、抽籤、專注鈴
🔐

登入密碼

  1. 密碼 = 你的字頭 + 今天的月日，例如 Teacher1014
  2. 新安裝時字頭是 Admin，第一次登入會要求你改成自己的字頭
  3. 字頭至少 4 個字，不能是 Admin，請不要告訴學生
忘記字頭：在登入畫面按「忘記密碼」，只能在老師自己的電腦操作。
👨‍🎓

第一次：建班級、加學生

  1. 點上方 ➕，輸入班級名稱，選導師班級或科任課程
  2. ⚙️ 設定 ➔ 學生名冊管理 ➔ 📥 批次匯入
  3. 下載 Excel 範本填好上傳，或直接把名單複製貼上
📱

讓學生連線

  1. 點 ⚙️ 設定，按右側 📱 學生連線 QR Code
  2. 點 QR Code 放大到全螢幕，投影給全班
  3. 學生用手機或平板掃描，輸入帳號、密碼

學生預設密碼是學號（沒填學號才用座號四碼）。第一次登入會自己設定新密碼。電腦和手機要連同一個 Wi-Fi。

⭐

上課中：加分與點名

⭐即時評分點學生，選項目就加分；按 ⚡ 可以一直點 +1
↩️按錯了加分後 2.5 秒內按「復原」
📋出缺席點名按「全班出席」，只改沒來的人
📺大螢幕投影排行榜，加分即時更新
🎮

課堂互動小遊戲

☁️文字雲學生手機送詞，詞越多字越大
🎮答題競賽像搶答遊戲，答對又快分數高
🎨互動牆學生的畫和照片秀在大螢幕
🎲抽籤、計時抽人上台、倒數計時
📁

請學生交照片、影片

  1. 📚 教材與作業 ➔ 📁 檔案蒐集 ➔ ➕ 建立蒐集主題
  2. 勾「立即開放學生上傳」，學生就看得到
  3. 👀 查看收件成果，可以直接看，也能 📦 一次打包下載
🎥 學生用「高畫質拍攝」，畫質不會被壓縮。
📚

教材、作業與測驗

📘課程素材放檔案、影片、網址給學生看
📝作業學生交，老師填分數和評語
✅線上測驗交卷後系統自動批改
📥掃描收作業掃 QR Code 貼紙就登記（僅限老師電腦）
🗓️

我的課表：上課時間到了提醒你

  1. ⚙️ 設定 ➔ 🗓️ 我的課表，選導師或科任
  2. 加入你教的班級和科目
  3. 點格子排課；之後系統會提醒「現在這一節是哪一班」
🏆

看成果、發獎勵

📊儀表板當天、當週、當月、整學期排行
🎁兌換商城學生用點數換獎勵
🎫點數卡學生掃卡片自動加分
📑Excel 報表期末一次匯出
🙋
