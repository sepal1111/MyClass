系統能幫你做什麼？

🚀課堂進行即時評分、儀表板與排行榜、特殊表現紀錄（文字／照片／影片）、教學互動工具（抽籤、計時、互動牆、文字雲、競賽）
📋班級經營出缺席點名、在位掌握、教學日誌
📚教材與作業課程素材、檔案蒐集、作業掃描登記、紙本測驗
🏆激勵與統計獎勵兌換、點數卡、報表匯出
⚙️設定名冊、座位表、分組、評分項目、標誌、密碼與連線、使用說明
🧰常駐懸浮條右下角常駐：⏱️ 快速計時、🎲 快速抽籤、🔔 專注鈴
📱

第一步：讓學生連線

  1. 點 ⚙️ 設定
  2. 按右側 📱 學生連線 QR Code
  3. 點 QR Code 全螢幕投影，學生掃碼登入

老師用手機走動操作？按旁邊的 📱 手機評分連線 QR Code，掃碼後輸入教師密碼，選班級就能點名、加減分、記錄、發公告、計時、抽籤。

⭐

上課中：評分與點名

⭐即時評分點學生或小組，選評分項目加扣分
📋出缺席點名一鍵標記出席、請假、缺席
📺大螢幕開投影視窗，全班同步看排行
🧰

課堂互動小工具

☁️文字雲學生手機投稿，詞越多字越大
🎮答題競賽像 Kahoot，可匯入 LMS 題庫或 CSV
🎲隨機抽籤抽學生或小組上台
⏱️計時器倒數、碼錶、背景音樂
📁

請學生交照片、影片

  1. 📚 教材與作業 ➔ 📁 檔案蒐集 ➔ ➕ 建立蒐集主題
  2. 勾「立即開放學生上傳」，學生就看得到
  3. 👀 查看收件成果，可預覽影音、📦 一鍵 ZIP 下載
🎥 學生用 「高畫質拍攝」 錄影、拍照，畫質不會被壓縮。
📥

收作業：掃一掃就登記

  1. 📚 教材與作業 ➔ 📥 作業掃描登記
  2. 建立作業項目，列印 QR Code 貼紙貼在作業簿
  3. 掃描 QR Code 就記錄「誰交了什麼」，也可交給小助手用獨立視窗掃
⚠️ 只能在 教師自己的電腦 使用，學生手機看不到這個功能。
📊
